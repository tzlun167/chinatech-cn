## 1. 背景

舊站 `www.chinatech-cn.com` 為 **WordPress + WooCommerce + Elementor** 建置，環境老舊且已不符資安要求：

| 項目 | 舊站現況 | 問題 |
|---|---|---|
| Web Server | Apache/2.2.15 (CentOS) | 2.2 於 2017 停止維護 |
| PHP | 7.2.34 | 2020 已 EOL，無安全更新 |
| CMS | WordPress | 需持續打補丁、易成攻擊目標 |
| 商業外掛 | WooCommerce + Elementor | 版本相容性與授權維護負擔 |

**結論：重建而非升級。** 舊站作為**內容與結構的參考基準**，不沿用其技術棧。

## 4. 待確認事項（需委託人回答）

1. **技術棧偏好？** 建議沿用既有經驗（NestJS + PostgreSQL + 前端框架），或採業界成熟 CMS？
2. **是否需要會員／購物車／線上付款？** 或維持型錄 + 詢價模式？
3. **14 項無描述的商品**如何處理（向原廠索取 / 保留空白 / 下架）？
4. **商品圖片**是否沿用舊站圖檔（需檢查授權與畫質），或提供新圖？
5. **多語系需求？** 舊站為簡體中文，是否需繁中／英文版？
6. **網域與主機**：`chinatech-cn.com` 網域目前指向舊站，新站部署於何處？（本機 gateway/其他主機/雲端）
7. **監控到訪**：僅需基本統計（GA4 / 自架 Plausible / Umami），或需後台內建報表？
8. **是否需 SEO 優化**（語意化網址、sitemap、meta）？
