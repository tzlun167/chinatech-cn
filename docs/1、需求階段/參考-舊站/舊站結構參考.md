## 技術指紋

```
HTTP/1.1 200 OK

Link: <.../index.php?rest_route=/>; rel="https://api.w.org/"
```

- CMS：**WordPress**（REST API 路徑 `index.php?rest_route=` 表示為無 rewrite 的設定）
- 電商：**WooCommerce**（`?post_type=product`、`?product=`、`?product_cat=`、`woocommerce-Price-amount`）
- 佈景／編輯器：**Elementor**（`?rs_elements=elementor-5301`、`rs_elements` 參數）
- 主題線索：Astra（CSS 內 `.ast-no-sidebar`、`.ast-container`）
- 註：`/wp-json/...` 回 404 → REST API 未開放（改走 `index.php?rest_route=`）

### sitemap.xml（80 筆 URL）

⚠️ **sitemap 內所有 URL 指向 `http://www.gd.chinatech.com.tw`，而非本站網域** — 設定錯誤（可能為外掛沿用舊網域殘留）。SEO 上有害。

其中約 39 筆為 `?product=` 商品頁、6 筆含 `product_cat`、其餘為分頁與 oembed 端點。

## SEO 缺陷（新站應修正）

1. **無語意化網址**：全站 query string（`/?product=...`），不利索引與分享
2. **sitemap 網域錯誤**：指向 `gd.chinatech.com.tw`
3. **標題重複**：「關於我們」「品牌」等頁 title 結構鬆散
4. **商品名稱包含行銷詞**：如 `PAV1010A高精度相位计 相角度分析仪 英国POWERTEK phase angle voltmeter` → 應拆分為「名稱 + 型號 + 品牌 + 描述」
5. **重複商品**：`TG1006 函数信号发生器` 與 `TG1006函数信号发生器`、`WA301 波形信号放大器` 與 `WA301波形信号发大器`（後者錯字）

