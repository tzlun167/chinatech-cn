# 02 — 資料模型規格書 v0.1

- **專案：** chinatech-cn 官網重建
- **日期：** 2026-11-09
- **狀態：** 草稿（對應 Payload CMS collection 設計）
- **上游：** `01-系統總覽-規格書-v0.1.md`

> 命名原則：collection slug 用複數英文小寫；欄位用 camelCase。

---

## 1. ER 概觀

```
brands ──1:N──> products ──N:M──> categories
                   │
                   ├──1:N──> product_specs (array, 內嵌)
                   ├──N:M──> media (images[])
                   └──1:1──> datasheet (media, 可空)

pages (關於我們 / 聯絡方式)
media (統一媒體庫)
users (後台帳號)
inquiries (詢價表單，條件式)
analytics_events (到訪事件，由 Umami 管，不進 Payload)
```

## 9. 到訪監控資料（R3）

**決策：交由 Umami 自架處理，不重複造表。**

| 表 | 由誰管理 | 說明 |
|---|---|---|
| `website_event` | Umami | 瀏覽事件（pageview、來源、UA、地區） |
| `session` | Umami | 訪客 session |
| `event` | Umami | 自訂事件（如 `inquiry_submit`） |
| `user` / `website` | Umami | 站點與帳號 |

Payload 端只需：

1. 前台注入 Umami 追蹤腳本（`<script defer src="/u/script.js" data-website-id="...">`）
2. 詢價送出成功後呼叫 `umami.track('inquiry_submit', {...})`
3. 後台「到訪報表」頁以 **iframe 內嵌 Umami dashboard**（或依 01 §3.4 指標自繪）

**隱私：** Umami 不使用 Cookie、不收集個資 → 無需 Cookie 同意橫幅。

## 10. 索引與約束

| 表 | 索引 | 理由 |
|---|---|---|
| products | `slug` unique | 網址查詢 |
| products | `status`, `publishedAt` | 前台過濾 |
| products | `brand_id`, `categories(product_id, category_id)` | 篩選 |
| categories | `slug` unique | |
| brands | `slug` unique | |
| media | `filename` | 去重 |
| inquiries | `status`, `createdAt` | 後台排序 |

**FK 刪除策略：**
- `products.brand` → `ON DELETE SET NULL`（品牌刪除不應連帶刪商品）
- `products.categories` → `ON DELETE CASCADE`（中介表）
- `products.images` → `ON DELETE SET NULL`（媒體刪除僅解除關聯）

## 11. 種子資料（39 商品）

來源：`docs/1、需求階段/參考-舊站/商品資料/`

| 檔 | 用途 |
|---|---|
| `商品清單-含描述.json` | 原始資料（標題／描述／分類／圖片 URL） |
| `商品清單.csv` | 人工檢視用 |
| `商品主檔-清理草稿.csv` | **自動解析草稿**：建議名稱／型號／品牌／分類 |

### 11.1 清理草稿的已知不足（需人工）

自動解析結果僅為**起點**，需人工確認：

1. **型號抽取不完整** — 39 筆中 34 筆未自動抓出型號（如 `EL系列`、`PSA 3系列` 屬系列名非單一型號）
2. **重複商品**：
   - `TG1006 函数信号发生器` ＝ `TG1006函数信号发生器`
   - `WA301 波形信号放大器` ＝ `WA301波形信号发大器`（後者為錯字）
3. **行銷詞需拆離**：
   - `PAV1010A高精度相位计 相角度分析仪 英国POWERTEK phase angle voltmeter`
     → 名稱 `PAV1010A 高精度相位计` / 品牌 `Powertek` / 描述 `相角度分析仪 (phase angle voltmeter)`
   - `PSM1700频率响应分析仪 电源环路分析仪 英国N4L品牌 PSM系列`
     → 名稱 `PSM1700 频率响应分析仪` / 品牌 `N4L` / 描述 `电源环路分析仪`
   - `PXE2640功率分析仪 1-4通道可选`
     → 名稱 `PXE2640 功率分析仪` / 規格 `通道數：1–4 可選`
4. **14 筆無描述** 需向委託人／原廠索取（清單見 `需求確認書-v0.1.md` §4）
5. **圖片** 需自 `wp-content/uploads/` 下載後入庫，並補 `alt`

### 11.2 Seed 腳本規劃（`scripts/seed-products.ts`）

```
讀取 商品清單-含描述.json
  → 正規化（名稱／型號／分類對應）
  → upsert brands / categories
  → 下載圖片（--download-images）→ media
  → upsert products（status: draft）
  → 輸出 seed-report.md（成功 / 失敗 / 待人工清單）
```

**冪等性：** 以 `slug` 為 key upsert，可重複執行。
